功能说明

拖拽安装（推荐）

Autodesk Maya 2025 — 未命名场景
拖到这里
MEL install.mel

真实操作：在资源管理器里选中 install.mel，按住左键拖到 Maya 主窗口（视口或工具栏均可）后松开。

安装完成（模拟）
  • Maya 版本：2025
  • numpy：已解压 numpy-1.26.4-cp311-cp311-win_amd64.whl
  • 已复制到：Documents/maya/2025/scripts
  • 工具栏：LINGJU 标签页 → 按钮「零距建模」
  • 点新图标即可打开工具，无需重启 Maya。

装完之后

打开面板

点工具栏 LINGJU 标签页里的「零距建模」图标。面板是可停靠的 workspaceControl，可以拖到 Maya 左右两侧或浮动。

升级 / 换版本

拿到新安装包后再拖一次 install.mel 即可：安装器会清掉旧按钮再建新的，pyd 直接覆盖。不同 Maya 版本互不影响。

卸载

删掉 scripts 里的 Lingju_Modeling_Tools_v175_*.pyd 与图标，再在 Shelf Editor 里删掉 LINGJU 标签页上的按钮即可，不会留下注册表或偏好设置残留。

v1.75
  • 智能分离选中面时改用 Maya 原生的 Extract Face（Edit Mesh 菜单命令，内部为 performPolyChipOff + 分离），不再走自写的复制 / 反选 / 删除算法。
  • 复制面为「是」时等于 Maya 的 Duplicate Face（保留原面），为「否」时等于 Extract Face（抽走原面）。
  • 分离后自动只选中抽出的新片，居中轴心，并清理原物体与新片的构造历史。
  • 删除旧的复制 / 反选 / 删除中间步骤及相关无用代码；选物体的按壳分离流程保持不变。
v1.74
  • 面板改为选项卡布局：建模 / 选择 / 命名 / UV / 烘焙五个分区，同一时间只显示一个，命令再多也不用一路往下滚。
  • 选项卡支持拖动排序、双击弹出独立窗口；右键标签可弹出当前分区、合并全部已弹出的窗口。
  • 关闭独立窗口会自动合并回主面板原来的位置，不用重新打开工具。
  • 打直UV 按钮加宽到 330，与选项卡内容区对齐。
  • 数值框悬停滚轮（扭曲阈值 / 按角度选面 / UV检查 / 棋盘格）与 v1.73 一致。
v1.73
  • 扭曲阈值数值框支持悬停滚轮，步长 1，范围 0–180，与滑条双向同步并写回 optionVar。
  • 按角度选面的角度数值框支持滚轮，步长 1，范围 0–180，改完立即刷新选择预览。
  • UV 检查：贴图大小步长 256（0–8192）、棋盘格1大小步长 256（0–1024）、棋盘格2大小步长 8（最小 4）。
  • 滚轮绑定改为全局共享：扭曲面检查 / 按角度选面 / UV检查 / 边重建 共用一套注册表，折叠栏展开时自动补挂。
v1.72
  • UV检查 / 传递UV 折叠栏宽度与内边距对齐智能合并分离（299 / marginWidth 10）。
  • 按钮宽度与间距对齐快速底面：成对 136、整行 275、高 28。
  • 打直UV 与折叠栏同宽（299），并留出 5px 间隔。
  • 边重建数值框去掉 ▲▼ 步进按钮，只保留悬停滚轮。
v1.71
  • 边重建各数值框支持悬停滚轮调节，步长与字段 step 一致，手感同 QSpinBox。
  • Qt 侧不可用时自动退回 Ctrl+拖拽，不影响界面构建。
v1.70
  • 新增边重建折叠栏（位于智能合并分离之上），内嵌 ResampleMesh_Maya 的重采样 / 平滑 / 圆化 / 解结 / 桥接五个子折叠栏。
  • 实时预览放在最外层：勾选后缓存原始点位，改参数时先还原再重算；重采样预览固定只调点位、不改点数与拓扑。
  • 保留双链分别设点数：正好选中两条开放边链时可分别指定目标点数。
  • 窗口、状态提示、工具架按钮、快捷键安装未搬运；结果与错误统一走视口提示。
